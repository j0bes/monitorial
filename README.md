# Monitorial
> version 4.0 beta
## The project
**Monitorial** is a network scanner, which returns the machines that are active on the network as well as the open ports.
<br>
It also provides practical information on open ports, such as potential high-risk ports. And new machine connected, compared to the previous scan (if exists).
